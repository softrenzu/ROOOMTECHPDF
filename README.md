# ROUOOMTECH PDF

ブラウザ内だけでPDFを編集し、編集済みPDFを書き出せるWebアプリです。ファイルはサーバーへ送信せず、端末内で処理します。

## 主な機能

- PDFのドラッグ＆ドロップ読み込み
- 文字修正（白背景で元文字を隠して置換）・文字追加
- 四角、楕円、線、矢印、手書き、マーカー、白塗り
- PNG・JPEG・WebP画像の挿入
- オブジェクトの移動、サイズ変更、複製、削除、Undo / Redo
- ページの移動、回転、複製、削除、白紙ページ追加
- 画質を選んでPDF保存
- PC・スマートフォン対応

## プライバシー

PDFと画像はブラウザ内で処理され、外部サーバーへアップロードされません。

## 技術

- PDF.js（PDF表示）
- pdf-lib（PDF生成）
- HTML / CSS / JavaScript
